ABC ZOOM · คู่มือสำหรับผู้เริ่มต้น

ตั้งค่าครั้งเดียว
หลังจากนั้นจัดการผ่านหน้าเว็บ

1. สร้างฐานข้อมูลใหม่แยกจากระบบเดิม

  1. เปิด Supabase Dashboard แล้วเข้าสู่ระบบ
  2. เลือก Organization ที่ต้องการ หากยังไม่มีให้สร้าง Organization ใหม่ ตรวจสอบแผนและค่าใช้จ่ายบนหน้าจอ
  3. กด New project ตั้งชื่อ abc-zoom-booking เลือกภูมิภาค Singapore และตั้งรหัสผ่านฐานข้อมูล เก็บรหัสผ่านไว้กับตัว
  4. รอให้ Project พร้อม แล้วส่งลิงก์หน้า Project ให้ผู้ช่วยในแชตนี้

ไม่ต้องส่งรหัสผ่านฐานข้อมูลหรือ Secret key ในแชต ให้เชื่อมปลั๊กอิน Supabase กับบัญชีที่มี Project ใหม่นี้ แล้วผู้ช่วยจะติดตั้งตารางและระบบหลังบ้านให้

2. เปิดเว็บผ่าน GitHub

  1. เปิด สร้าง repository บน GitHub ตั้งชื่อ abc-zoom-booking
  2. เชื่อมปลั๊กอิน GitHub ใน Codex ให้เข้าถึง repository นี้ แล้วส่งลิงก์ repository ในแชต
  3. ผู้ช่วยจะนำไฟล์เว็บขึ้นให้ จากนั้นเปิด Settings → Pages เลือก Source เป็น GitHub Actions

GitHub เก็บเฉพาะไฟล์เว็บ ส่วนข้อมูลการจองและรหัสผ่าน Zoom อยู่ใน Supabase Project ใหม่

3. ตั้งบัญชีผู้ดูแลครั้งแรก

ใน Supabase Project ใหม่ เปิด Authentication → Users → Add user ใช้อีเมล nattawat.suw@mail.wu.ac.th ตั้งรหัสผ่านด้วยตัวเอง และยืนยันอีเมลตามขั้นตอนของ Supabase จากนั้นกลับหน้าเว็บ → ผู้ดูแลระบบ → เข้าสู่ระบบ

รหัสผ่าน Admin คือรหัสผ่านที่ตั้งในขั้นตอนนี้ ไม่ใช่รหัสผ่านของบัญชี Zoom

4. งานประจำ ทำผ่านหน้า Admin

  • เลือกบัญชี Zoom เพื่อแก้ชื่อ อีเมล รหัสผ่าน หรือปิดรับจองชั่วคราว
  • เปิดตารางเวลา/รายการเพื่อดูรายละเอียดและยกเลิกการจอง พร้อมระบุเหตุผล
  • ดูและดาวน์โหลดประวัติการเปลี่ยนแปลง รวมถึงผู้ยกเลิก

ผู้จองไม่ต้องล็อกอิน เมื่อจองสำเร็จให้ดาวน์โหลดหลักฐาน เก็บรหัสยกเลิกไว้ ใช้รหัสนี้เปิดดูข้อมูลเข้าสู่ระบบ Zoom หรือยกเลิกการจองได้

ชื่อที่ผู้จองกรอกเป็นชื่อที่แจ้งเอง รหัสประจำการจองช่วยควบคุมสิทธิ์ แต่ไม่ยืนยันตัวบุคคล ผู้ดูแลที่ล็อกอินแล้วจะแยกแสดงเป็นบัญชีที่ยืนยันแล้ว

สถานะตอนนี้: ติดตั้งและเชื่อม Supabase Project ใหม่แล้ว เหลือตั้งบัญชี Admin กรอกรหัสผ่าน Zoom และเผยแพร่ผ่าน GitHub
