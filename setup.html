วิธีใช้งาน ABC Zoom

สร้างการจอง

  1. เลือกวันที่และดูช่วงเวลาว่างจากตารางเวลา
  2. กดสร้างการจอง ใส่ชื่อ หัวข้อ วัตถุประสงค์ และเลือกบัญชี Zoom
  3. กำหนดเวลา 00:01–23:59 น. เลือกจองซ้ำได้ตามต้องการ แล้วกดยืนยัน
  4. ข้อมูลเข้าสู่ระบบ Zoom จะแสดงหลังจองสำเร็จ สามารถดาวน์โหลดหลักฐานไว้ได้

ยกเลิกโดยไม่ต้องกรอกรหัส

  1. เปิดเว็บด้วยเบราว์เซอร์และอุปกรณ์ที่ใช้จอง
  2. แตะแถบการจองหรือรายการของคุณ แล้วกดยกเลิกการจอง
  3. ตรวจชื่อผู้ยกเลิก ระบุเหตุผล และเลือกยกเลิกเฉพาะครั้งหรือทั้งชุด

ระบบจำสิทธิ์ไว้ในเบราว์เซอร์ให้อัตโนมัติ หากเปลี่ยนอุปกรณ์ ล้างข้อมูลเบราว์เซอร์ หรือเป็นรายการเก่าที่สร้างก่อนการปรับปรุงนี้ ให้ติดต่อผู้ดูแลเพื่อช่วยจัดการ การยกเลิกทุกครั้งมีประวัติบันทึก

English guide

Select a date, check availability, then choose New booking. Enter your name, meeting details, Zoom account and time. Recurring bookings are supported.

To cancel, use the same device and browser you booked with. Open your booking, select Cancel booking, enter your name and reason, then confirm the scope. No code is required.

If you change browsers, clear browser data, or need help with a booking made before this update, contact an administrator. All cancellations are logged.
