# ABC Zoom Booking

ระบบจอง Zoom สำนักวิชาการบัญชีและการเงิน มหาวิทยาลัยวลัยลักษณ์

- Gantt timeline ธีมเหลือง ขาว แดง พร้อมโลโก้สำนักวิชา
- ไทย / English ธีมสว่าง / มืด รองรับมือถือ
- จองโดยไม่ล็อกอิน เวลาไทย 00:01–23:59
- จองซ้ำรายวัน รายสัปดาห์ รายเดือน
- ยกเลิกได้ทุกอุปกรณ์โดยกรอกชื่อผู้ยกเลิกและเหตุผล ไม่ต้องใช้รหัส
- บันทึกประวัติให้ Admin ตรวจสอบ ชื่อบุคคลทั่วไปเป็นข้อมูลที่กรอกเอง
- Admin จัดการบัญชี Zoom และดูประวัติ

ข้อมูลการจองและรหัสผ่าน Zoom เก็บใน Supabase Project แยก ไม่อยู่ใน repository นี้
